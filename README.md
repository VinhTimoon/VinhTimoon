## Featured Projects

### DevCare — Pull Request Risk Management Platform

A software engineering platform focused on **academic development-team governance, GitHub integration, Pull Request analysis, and risk-based review prioritization**.

The backend is designed as a **NestJS modular monolith** with separate worker processes for provider operations, notifications, academic jobs, tasks, and code analysis.

**Core technologies**

`NestJS` `TypeScript` `Fastify` `PostgreSQL` `Prisma` `Redis` `BullMQ` `Docker` `Socket.IO` `MinIO / S3` `SonarQube` `GitHub API`

**Highlights**

- GitHub organization, repository, team, and OAuth integration
- Academic course, class, enrollment, and team governance
- Pull Request snapshot and analysis pipeline
- Background processing with Redis and BullMQ
- Dedicated analysis, provider, notification, academic, and task workers
- Static analysis and evidence collection for code-review prioritization
- Object-storage based artifact/evidence workflow
- Authentication with short-lived access tokens and revocable sessions
- CI/CD and automated quality gates
- Provider recovery, replay, audit, and failure-handling workflows
